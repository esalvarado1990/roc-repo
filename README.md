# Roc Repo

Personal Kodi repository. Add this source in Kodi: https://esalvarado1990.github.io/roc-repo/

Current builds: **v2.0.0** — Roc Gold, Haunted, Night Route, Noir Raven and Sesh Lounge, each in Lite / Medium / Powerhouse tiers, all wearing the Roc OS interface (skin.rocos) as the default skin. The Roc Builds Installer (2.0.0) verifies every download against its published SHA-256 fingerprint before installing, backs up your current setup first, and finishes the install itself (addons enabled, skin set, services lockdown applied). Trakt ships installed but off — sign in once, in one sitting, after the build settles.

The v1.0.0 release stays available under Releases for rollback.
