# Roc Repo

Personal Kodi repository. Add this source in Kodi: https://esalvarado1990.github.io/roc-repo/

Current builds: **v2.2.0** (v2.0.0 notes below still apply; 2.1.0 added the Up Next service for autoplay-next-episode and baked the source-quality rule: quality-first source order with a 1080p cap on Lite, 4K open on Medium/Powerhouse; 2.2.0 adds the Roc OS **Music Room** — a dedicated music section in every build: trending music videos, artist shelves and full albums from the Internet Archive, plus your own library — and **vendors Archive Theater into this repo** (see VENDORED.md), so the PythonTrousers repository is no longer needed or included) — Roc Gold, Haunted, Night Route, Noir Raven and Sesh Lounge, each in Lite / Medium / Powerhouse tiers, all wearing the Roc OS interface (skin.rocos) as the default skin. The Roc Builds Installer (2.0.0) verifies every download against its published SHA-256 fingerprint before installing, backs up your current setup first, and finishes the install itself (addons enabled, skin set, services lockdown applied). Trakt ships installed but off — sign in once, in one sitting, after the build settles.

The v1.0.0 release stays available under Releases for rollback.
